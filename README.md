# 🎵 Tiddl-GUI
An elegant, modern, and high-performance Web GUI for downloading high-quality music from TIDAL.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Node.js](https://img.shields.io/badge/node.js-%3E%3D16-green.svg)
![TIDAL](https://img.shields.io/badge/service-TIDAL-00C9FF.svg)

## ✨ Features
- **Dark Glassmorphism UI**: A stunning, premium interface for a better user experience.
- **WebSocket Logs**: Real-time download progress and terminal logs directly in your browser.
- **High Quality Audio**: Choose your preferred quality (Normal, High, Lossless, Max).
- **Metadata & Cover Art**: Automatically embeds album covers and lyrics into your music files.
- **Custom Paths**: Easily select your download folder using native macOS file picker integration.
- **Session Management**: Native TIDAL authentication handling.

## 🚀 Getting Started
1. Install dependencies: `npm install`
2. Start the server: `node server.js`
3. Open your browser at `http://localhost:7432`
4. Authenticate your TIDAL account and start downloading!

## 🛠️ Built With
- **Backend**: Node.js, Express, Socket.io
- **Downloader**: tiddl-elvigilante (CLI)
- **Design**: Vanilla CSS (Custom Glassmorphism)
